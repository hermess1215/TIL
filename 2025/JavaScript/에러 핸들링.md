## try…catch

try…catch는 주로 에러를 잡을 때에 사용한다.

### 에러는…

1. 발생시킬 때 → 던진다고 한다.    (throw)
2. 명시적으로 인지할 때 → 잡는다고 한다.    (catch)

```javascript
function runner() {
    console.log('Hello')

    throw new Error('큰 문제가 생겼습니다.')

    console.log('Code Factory')
}

runner()
```

출력 결과

Hello

Error: 큰 문제가 생겼습니다.

```javascript
function runner() {
    try {
        console.log('Hello')
    
        throw new Error('큰 문제가 생겼습니다.')
    
        console.log('Code Factory')
    } catch(e) {
        console.log('---catch---')
        console.log(e)
    } finally {
        console.log('---finally---')
    }
}

runner()
```

출력 결과

Hello

—catch—

Error: 큰 문제가 생겼습니다.

—finally—

### try

실행하고 싶은 코드를 **try** 안에 넣는다.

### catch

에러가 발생한다면 실행할 코드를 **catch** 안에 넣는다.

### finally

try에서 에러가 나든 안 나든 무조건 실행하는 코드를 **finally** 안에 넣는다.

전체 코드

```javascript
function runner() {
    try {
        console.log('Hello')
    
        throw new Error('큰 문제가 생겼습니다.')
    
        console.log('Code Factory')
    } catch(e) {
        console.log('---catch---')
        console.log(e)
    } finally {
        console.log('---finally---')
    }
}

runner()
```
